# Album covers

Yahaan har gaane ke liye square (1:1) cover image daalo — `.jpg` ya `.png`.
Recommended size: 500x500 ya 800x800 pixels.

Filename wahi rakhna jo `playlist.js` mein `cover` field mein likhoge.

Example:
- `songs/ye-shaam-mastani.mp3`  →  `covers/ye-shaam-mastani.jpg`

Agar cover nahi hai toh `playlist.js` mein `cover` field chhod do — player
apne aap wooden/lantern fallback use karega.
